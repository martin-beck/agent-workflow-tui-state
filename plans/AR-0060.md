# AR-0060: GUI screenshot scenarios and documentation

Extend the generated scenario corpus to cover the Windows GUI and equivalent
TUI flows. Produce deterministic, redacted screenshots or recordings for
document switching, source highlights, batch decisions, proposal editing,
clarification, unsaved exit, resize, reconnect, and resolved output. Link
each artifact to an accessible Markdown workflow so users can understand the
interaction without running the application first.

Acceptance criteria:

- Artifacts are generated by the same scenario inputs used by automated tests,
  not hand-edited screenshots.
- TUI and GUI scenarios assert equivalent revision-bound outputs and clearly
  label platform-specific presentation differences.
- Capture tooling removes credentials, private paths, host identifiers, raw
  prompts, and unbounded terminal history.
- Documentation is updated automatically and remains usable offline.

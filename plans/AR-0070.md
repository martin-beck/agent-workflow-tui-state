# AR-0070: Canonical live event envelope

Ensure every live TUI/GUI event written to the Coordinator bridge uses the
versioned envelope shape: identity and sequence at the envelope level, with
all decision fields inside `payload`. Add schema-level regression tests and
release/pin the compatible implementation.

Acceptance:

- live transport output validates against the published TUI event contract;
- select, reject, clarification, evidence, proposal, reopen, and safe-exit
  events retain their payload fields;
- Coordinator bridge projection consumes the emitted event without adapter
  special cases;
- focused and hosted CI tests pass, with exact release and umbrella pin
  evidence recorded.

# AR-0062: Align UI package metadata with the released compatibility line

The UI source used for the public compatibility lock must declare the same
version as the release selected by the umbrella project.  A release that
contains `v0.4.x` behavior but reports an older package version can install
successfully while defeating dependency and provenance checks.

Acceptance criteria:

- The package metadata declares the next patch release version.
- A focused test fails if the package metadata regresses to the old version.
- The fix is merged, released, and the umbrella compatibility lock is updated
  to the immutable release commit.
- Hosted Linux scenario/GUI and Windows compatibility checks pass at that
  exact commit.

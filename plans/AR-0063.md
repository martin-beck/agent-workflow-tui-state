# AR-0063: Negotiate GUI versus TUI for remote clients

Remote SSH does not reveal the client operating system or whether a graphical
session is usable. The host adapter must therefore carry an explicit GUI
capability and select the GUI only when it is available, retaining the TUI as a
safe fallback.

Acceptance criteria:

- Windows/PowerShell capability envelopes may state `gui_available`.
- Remote handoff emits `awui-live` for GUI-capable clients and `awtui-live`
  otherwise.
- Missing capability preserves the backwards-compatible GUI preference.
- Schema, docs, and focused Linux/Windows-compatible tests cover both paths.

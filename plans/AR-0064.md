# AR-0064: Professional GUI visual system and interaction help

Adopt Qt's native style foundation with a restrained high-contrast palette,
clear primary/secondary/destructive action hierarchy, consistent spacing, and
short tooltips. Essential instructions remain visible in the window; tooltips
only add context and keyboard hints. Verify with offscreen widget tests and
scenario screenshots.

References: GNOME HIG tooltips and buttons, Microsoft Windows tooltip guidance,
Qt Widgets styling and Textual's keyboard-first widget model.

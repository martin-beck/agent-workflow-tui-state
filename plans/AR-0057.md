# AR-0057: Cross-platform TUI CI and compatibility

Create a CI matrix that exercises the complete request-to-TUI-to-Coordinator
response path on supported Linux and Windows environments, with remote
transport tests where the runner can provide an isolated SSH fixture. Check
the pinned contract versions and release compatibility of TUI, Coordinator,
Guidance, and Quality before publication.

Acceptance criteria:

- CI covers Python/runtime versions, terminal widths, Unicode capability,
  Windows console behavior, local sessions, detached/reattached sessions,
  and stale response rejection.
- Scenario tests produce deterministic redacted logs/screenshots and do not
  require credentials or an internet service.
- A compatibility gate fails closed when any required contract or release
  pin is stale, missing, or mismatched.
- The documented release procedure distinguishes source-only validation from
  an installable, published release.

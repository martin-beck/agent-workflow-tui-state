# AR-0056: Remote TUI session transport

Provide a transport-neutral, bounded adapter for attaching a TUI session over
SSH or another explicitly configured network boundary. Transport is not
allowed to alter AWG semantics: every request and response remains bound to
project, AR, task revision, request reference, session ID, sequence, and
contract version. The Coordinator remains the persistence authority.

Acceptance criteria:

- Local, SSH, disconnected, reattached, stale, duplicate, and timeout cases
  have deterministic tests.
- Host authentication, finite deadlines, reconnect behavior, and redaction
  requirements are documented; no credentials or raw input are persisted.
- Detached sessions remain explicitly awaiting response and cannot authorize
  autonomous work until a valid response is committed.
- The adapter has no mandatory network dependency for local TUI operation.

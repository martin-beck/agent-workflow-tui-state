# AR-0065: Single-command cross-platform UI handoff

Add an installed `awui-connect` entry point. The command accepts a session
file and optional SSH alias, detects the local platform/display, chooses GUI
when usable and TUI otherwise, performs bounded request/result transfer through
OpenSSH/scp, and leaves the Coordinator-owned result at its original path.
The agent prints only this short command plus a one-line explanation.

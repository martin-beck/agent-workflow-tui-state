# AR-0059: Windows PowerShell SSH capability contract

Define the supported Windows PowerShell command shape for attaching to a
remote TUI/GUI session over SSH and for invoking bounded remote-agent
operations. The contract must describe capability negotiation, quoting and
encoding rules, terminal/GUI forwarding limits, deadlines, cancellation,
exit-status classification, reconnect behavior, and public-safe diagnostics.

Acceptance criteria:

- PowerShell 5.1 and PowerShell 7 behavior is either supported and tested or
  explicitly rejected with a clear diagnostic.
- Commands are finite argument arrays or an equivalently escaped reviewed
  representation; arbitrary unbounded shell text is not accepted.
- Host identity, session ID, AR revision, request reference, sequence, and
  capability digest are bound before any remote action is accepted.
- Authentication material, private paths, raw prompts, and command output are
  never persisted in task state or scenario artifacts.
